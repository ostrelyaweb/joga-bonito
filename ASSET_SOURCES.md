# Item artwork

Joga Bonito is a standalone application. It does not import, launch, or require
Shift or any Shift installation.

Rocket League item artwork was derived from the public `itemchanger/assets`
collection and optimized for the inventory UI under `assets/item_icons/`.
The artwork is bundled with Joga Bonito; the application performs no network
request and works offline. If no individual artwork exists for a package, Joga
Bonito uses its bundled category artwork.

Asset collection:
https://github.com/itemchanger/assets
